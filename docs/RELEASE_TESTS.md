# 배포 검증 기록

대상: UnionDrive 0.2.0 / Windows 11 x64 / .NET 10.0.12

## 완료한 검증

- Release 솔루션 빌드: 경고 0 / 오류 0.
- 자동 검증 43개: 프로필/HTTPS/중복 drive, credential 저장·삭제, dirty cache, 설치 환경/remote 누락, 인증 사전 확인 실패, redirected pipes, 인증 RC, 연결/해제/재연결, 비정상 종료, 세션 종료, 다중 마운트 독립성, 소유권 복구.
- 30회 UI 생성/폐기에서 GDI/User 핸들 `(15, 12)` → `(15, 12)`.
- 10회 managed mount 재연결에서 Session 레코드 회수.
- 공식 rclone 1.75.1: stdin obscure, --config NUL 환경 기반 remote, RC 인증/PID, core/quit의 정상 종료.
- 실제 앱 기본 화면과 설정 창을 Computer Use로 확인. 설정 취소 후 복귀 및 자체 정상 종료 명령 성공.
- 공식 rclone ZIP SHA256, WinFsp MSI 및 Inno Setup 도구 서명 확인.

자동 검증의 마운트는 테스트 프로세스입니다. 실제 드라이브 매핑/회사 NAS 데이터를 변경하지 않았습니다. Credential Manager 검증은 임시 고유 ID만 사용하고 해당 credential을 제거했습니다.

## 사용자 설치 테스트가 필요한 항목

1. 깨끗한 Windows에서 인스톨러 실행 → WinFsp 관리자 권한 승인 → 설치/재시작 여부 확인.
2. 앱에서 실제 NAS 프로필 두 개 이상 저장하고 서로 다른 문자를 선택.
3. 각 드라이브 연결 후 작은 테스트 파일 읽기/생성/수정 및 NAS 측 반영 확인.
4. 한 드라이브를 해제했을 때 다른 드라이브가 유지되는지 확인.
5. 각 프로필 설정 변경/재연결, 창 닫기 후 트레이, 명시적 종료 확인.
6. 로그인 자동 시작을 켠 후 로그오프/로그인 또는 재부팅으로 자동 연결 확인.
7. 제거를 취소하면 데이터가 보존되는지 확인. 제거를 확정하면 자신의 프로필/credential/cache/log/Run/설치 registry/앱 파일이 제거되는지 확인.
8. 처음에 WinFsp가 없던 PC는 함께 설치한 WinFsp 제거 확인. 기존 WinFsp가 있던 PC는 보존 확인.

실제 WinFsp driver 설치/제거 및 NAS 읽기/쓰기는 개발 호스트에서 검증하지 않았습니다. 장기간 여러 드라이브를 동시에 사용하는 환경의 메모리/CPU는 추가 측정이 필요합니다. 설치본은 코드 서명이 없는 테스트 배포본입니다.

## 0.2.3 사용자 확인 (2026-10-06)

- 변경: 서버 주소 예시 제거, TLS 오류 원인별 안내, 버전/패키징 0.2.3.
- 컴파일과 installer 패키징 완료. 이 수정본의 앱 실행·NAS 접속·설치·자동/회귀 테스트는 에이전트가 수행하지 않았다.
- 사용자가 제공한 DSM 화면에서 WebDAV Server에 접속 주소와 다른 주체 대체 이름의 자체 서명 인증서가 지정된 것을 확인했다.
- 사용자가 접속 주소의 인증서를 발급하고 WebDAV Server에 지정한 뒤 모든 기능이 정상 작동한다고 보고했다.
- 이 사용자 확인을 깨끗한 Windows에서의 설치/제거, 모든 NAS 환경 또는 장기 리소스 검증으로 확대하지 않는다.
